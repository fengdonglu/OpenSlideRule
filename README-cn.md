# OpenSlideRule

OpenSlideRule 是一个网页版的计算尺模拟器与创作工具。它内置中国 1002 型矢量重对数双面计算尺与 57 型袖珍尺，也能载入或设计任何以 `RuleDefinition` JSON 描述的规则——直尺式或圆盘式。读值方式与实物一致：靠滑动与对齐，而不是输入算式求和；内置的设计器把同一套渲染器变成制尺工具。它面向想学习如何读尺、用尺的人——计算尺的学生与教师、收藏者——也面向想自行设计并预览计算尺的制作者。

## 试用 / 本地运行

GitHub Pages 部署已在
[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) 中配置；向
`master` 或 `main` 推送即会构建并发布。若要在本地运行：

```bash
npm install
npm run dev
```

然后打开 <http://localhost:3000>（Vite 会自动打开）。需要 Node.js 20.19.4 或更高版本。

## 你可以做什么

**模拟器**

- 在标题选择器中选择型制：1002、单面的 57 型袖珍计算尺，或你导入的计算尺。
- 单面查看，或双面同屏查看（双面模式）；57 型为单面尺。
- 拖动滑尺（圆形尺则转动转盘），并可一键复位到对齐位置。
- 使用多个游标：在尺面上点击即可新增，拖动即可移动，或在读数面板中输入数值，把游标移到读出该值的位置。
- 在尺面上任意位置悬停，即可实时读出指针下每条标尺的值。
- 在读数面板中查看每个游标处各条标尺的读数，并可直接编辑读数来移动对应游标。
- 在 1X–6X 之间缩放。
- 六种主题（plastic、bamboo、contrast、aluminum、ivory、blueprint），主题也会改变界面外观。
- 在简体中文（zh-CN）与英文（en-US）之间切换界面语言。
- 将当前视图导出为 PNG 或 SVG，或将操作记录导出为 Markdown。
- 按 1:1 比例打印或另存为 PDF。
- 查看首次运行引导，并打开型制信息对话框，了解当前计算尺的尺寸、标尺与结构。

**计算尺设计器**

- 以内置型制为种子，或从起始模板开始（线性对数尺，或圆形 C/D 尺）。
- 编辑计算尺元数据、线性布局（尺面尺寸、行数、边沟），或圆形尺的盘面尺寸。
- 增删标尺、调整顺序，并编辑每条标尺的字段与计算。
- 使用与模拟器相同的渲染器实时预览。
- 在预览中或列表中点击标尺即可选中它。
- 关注校验状态栏，并将草稿导出为 `<id>.spec.json`，或将成品规则定义导出为 `<id>.rule.json`。

## 加载你自己的计算尺

使用工具栏的 **导入** 按钮，或将 `.json` 文件拖放到模拟器视图。文件必须是
`RuleDefinition`——与设计器和生成器产出的模式一致。格式错误、校验失败或不受支持的文件会给出提示，且不会影响当前视图。线性和圆形规则都受支持。
