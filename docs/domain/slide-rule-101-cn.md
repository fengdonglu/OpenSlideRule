# 计算尺基础

> 本文档是英文原版 [slide-rule-101.md](slide-rule-101.md) 的简体中文翻译；英文原版为规范版本（canonical），如有歧义以英文原版为准。

计算尺的原理、标尺类型与操作入门，不依赖任何特定型号。

---

## 1. 原理

### 1.1 对数
计算尺利用**对数**把乘法和除法变成加法和减法：
- **乘法**：`log(a x b) = log(a) + log(b)`
- **除法**：`log(a / b) = log(a) - log(b)`

在对数标尺上，**位置与数值的对数成正比**，因此两个数值之间的距离就是它们对数的差，把一条标尺相对另一条滑动，就是在对数空间里做加法 / 减法。

### 1.2 刻度映射
对于单个十进制段的标尺（例如 C/D），数值 v 的位置为：
```
position = (log10(v) - log10(vMin)) / (log10(vMax) - log10(vMin))
```
对于 C（1..10）：
- v = 1 -> 位置 0（左端）
- v = 10 -> 位置 1（右端）
- v = sqrt(10) ~ 3.162 -> 位置 0.5（中央）

## 2. 标尺类型

各标尺并非平起平坐。**C 和 D 是参考标尺**：几乎所有其他标尺都以它们为基准来分度、放置或读数。相对于 C/D "读数"的位置以 **C/D 十进制单位**表示 —— `0..1` 对应 C 的 `1..10`，一条标尺可以越过任一端，而它的刻度仍与所配合的 C/D 读数对齐。折叠标尺（CF/DF）、倒数标尺（CI/DI/CIF），以及对数、三角、双曲和对数-对数标尺，都由它们的数值落在 C/D 上的位置来定义。各型号的具体规则见 [model-1002.md 第 3.8 节](model-1002.md) 和 [model-57.md](model-57.md)。

### 2.1 对数标尺
| 标尺 | 范围 | 十进制段 | 用途 |
|---|---|---|---|
| C / D | 1 - 10 | 1 | 乘法与除法的核心 |
| A / B | 1 - 100 | 2 | 平方与平方根 |
| K | 1 - 1000 | 3 | 立方与立方根 |

刻度密度并不均匀：小端密集，大端稀疏。

### 2.2 折叠标尺
- **CF / DF**：把 C/D 折叠，使索引落在 sqrt(10) 处（在 1002 上）；范围从 sqrt(10) 到 10*sqrt(10)。
- **用途**：在长计算中减少索引切换次数。

### 2.3 倒数标尺
- **CI / DI / CIF**：C/D/CF 的倒数，**递减**排列（从右到左）。
- **用途**：除法（`a / b` 即 `a x (1/b)`）。

### 2.4 线性标尺
- **L / lg**：**线性**常用对数标尺，位置与数值成正比。
- **用途**：直接读出 log10，或用于指数。

### 2.5 三角标尺
- **S / T / ST**，以及 1002 上的 `sin2 / cos2 / tg2 / ctg2 / tg3 / ctg3`。
- 以**度**分度；读数为函数值。在 1002 上位置与 log(sin) 或 log(tan) 成正比。

### 2.6 双曲标尺
- **sh / th**，以及 1002 上的 `H2`（cosh）、`H'2`（sech）、`sh2/sh3`、`th2`。
- 用于工程与物理中的双曲函数。

### 2.7 标尺的角色与重要性
各标尺的使用频率并不相同。**C/D 及其折叠与倒数邻居（CF/DF、CI/DI）**承担日常的乘法与除法；**A/B 与 K**服务于平方、立方和开方，而 **L** 直接给出对数。其余标尺都是**专用**的 —— 三角、双曲、对数-对数 —— 使用频率低得多。计算尺的布局也据此设计：日常标尺就在最顺手处，而在圆形计算尺上，精度最高的标尺被安排在外圈。

## 3. 基本操作

### 3.1 乘法
示例：2 x 3
1. 把 C 的 **1** 对准 D 的 **2**
2. 把游标移到 C 的 **3**
3. 读游标下方的 D -> **6**

原因：动尺移动了 log10(2)，因此 C 的 3 现在位于
log10(2) + log10(3) = log10(6)。

### 3.2 除法
示例：6 / 2
1. 把游标放在 D 的 **6** 上
2. 移动动尺，使 C 的 **2** 位于游标下
3. 读 C 的 **1** 下方的 D -> **3**

或者用倒数标尺：把 C 的 1 对准 D 的 6，读 CI 的 2 下方的 D。

### 3.3 平方与平方根
- **平方**：读 D，在 A 上取结果。
- **平方根**：读 A，在 D 上取结果。

### 3.4 立方与立方根
- **立方**：读 D，在 K 上取结果。
- **立方根**：读 K，在 D 上取结果。

## 4. 读数精度

### 4.1 有效数字
计算尺给出 **3-4 位有效数字**。主（带标注）刻度最精确；中等和细刻度需要估读。

### 4.2 数量级
计算尺不显示小数点，因此数量级必须靠心算判断：
2 x 3 和 0.2 x 30 的摆法相同，都读作 "6"；答案究竟是 6、60、0.6 还是 0.06，由你决定。

---

## 5. 游标的作用

### 5.1 跨标尺对齐
透明游标同时覆盖上尺、动尺和下尺，因此一条线可以同时给出 C、D、A、K 及其余标尺的读数。

### 5.2 精确定位
游标线非常细，减小了视差误差。

### 5.3 单位换算（特殊游标）
某些游标带有一条**辅助线**（例如 HP 线），使两条标尺可以直接换算：主线上读一条标尺，辅助线上读另一条。

---

## 6. 局限

### 6.1 不适用
- **加法 / 减法**：用心算或查表完成。
- **超出标尺范围的数值**：需要做十的幂次移位。
- **高精度**：刻度密度把结果限制在 3-4 位有效数字。

### 6.2 误差来源
- 手动滑动时的对齐误差
- 斜角读数时的视差
- 中等与细刻度之间的估读

## 7. 本项目的两把原型尺

这里记录的两款型号均产自**中国**，且各自是其类别的代表：**1002** 为**桌面型**，
**五七型**为**便携型**。它们的设计起步于当时国外大厂的同类型号，但经中国业界改进
后，在布局、标尺配置上不逊于国外同类；就做工而言，据维护者评价也十分优秀。它们
在此作为项目的参考原型：一把全尺寸尺与一把袖珍尺，正是计算尺在实践中的两种形态。

- **1002** —— 桌面型，双面，矢量重对数；见 [model-1002-cn.md](model-1002-cn.md)。
- **五七型** —— 便携型，单面；见 [model-57-cn.md](model-57-cn.md)。
