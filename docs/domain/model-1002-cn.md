# 中国 1002 型计算尺 - 物理规格
*中国 1002 型计算尺的物理规格*

> 本文档是英文原版 [model-1002.md](model-1002.md) 的简体中文翻译；英文原版为规范版本（canonical），如有歧义以英文原版为准。

本文仅描述**实体计算尺**，与软件实现无关。

## 1. 基本信息

- **正式名称**：矢量重对数双面计算尺（Vector Log-Log Double-Sided Slide Rule）
- **简称**：矢量双面计算尺
- **型号**：1002
- **类型**：双面线性计算尺
- **形式**：长条

## 2. 物理结构

### 2.1 三段式结构
```
+-------------------------------------------------------------+
|                    Upper fixed scale                        |
+-------------------------------------------------------------+
|                    Upper groove (slot)                      |
+-------------------------------------------------------------+
|                    Slide (movable middle part)               |
+-------------------------------------------------------------+
|                    Lower groove (slot)                      |
+-------------------------------------------------------------+
|                    Lower fixed scale                        |
+-------------------------------------------------------------+
```

- **上 / 下固定标尺**：固定在尺体上。
- **动尺**：在两条缝中水平滑动。
- **缝**：实际上是一条宽间隙，被一条发线（缝边）横穿。

### 2.2 两个面
每个面都有自己的上 / 中 / 下结构。两个面是同一尺体的两侧；绕长轴翻转尺子即可看到另一面。

### 2.3 尺寸与比例
1002 是**全尺寸桌面计算尺**：尺面（印刷区域）约为**1 英尺长、2 英寸宽**。

| 项目 | 测得值 | 说明 |
|---|---|---|
| 尺面尺寸 | 304.8 x 50.8 mm（12in x 2in） | 长宽比恰好为 **6 : 1** |
| 每面行数 | 14 | 上 4 / 中 6 / 下 4 |
| 行高 | ~3.14 mm | 由总高度解出 |
| 缝（上 / 下） | ~0.7 x 行高 | 带一条细线的宽间隙 |
| 上 / 下留白 | ~0.4 x 行高 | 尺面边缘 |
| 左侧名称栏 | ~26 mm | 标尺名称（sh2、K、sin2……） |
| 右侧参考面板 | ~20 mm | 换算说明与公式 |
| 数字高度 | ~0.6 x 行高 | 实体尺非常密集 |

**刻度区**：`304.8 - 26 - 20 ~ 259 mm`，刻度的水平范围。

> **来源**：由照片 `1002-front.jpg` / `1002-back.jpg` 测得
> （约 11.4 px/mm），因此这些是**估计值**，有待对照实体计算尺或厂商数据进一步精化。
> 在代码中，它们位于 `packages/core/rules/1002.json` 的 `physical` 字段 /
> `PhysicalSpec` 类型。

### 2.4 右侧参考面板（待补充）

## 3. 标尺

### 3.1 数量与分布
- **总计**：28 条标尺
- **每面**：14
- **每面**：上 4 / 中 6 / 下 4

### 3.2 正面，自上而下
> 权威来源：照片 `1002-front.jpg`。

**上尺**：`sh2 / sh3 / K / A`
**动尺**：`B / sin2(cos2) / H'2 / tg2(ctg2) / tg3(ctg3) / C`
**下尺**：`D / DI / lg / th2`

### 3.3 背面，自上而下
> 权威来源：照片 `1002-back.jpg`。

**上尺**：`ln1I / ln2I / ln3I / DF`
**动尺**：`CF / CIF / H2 / H3 / CI / C`
**下尺**：`D / ln3 / ln2 / ln1`

> **注意**：本文档 v1.0 把两个面弄反了；v1.1 依据照片更正。

### 3.4 命名约定
- **红色标尺**是递减的（数值从大到小）。
- **黑色标尺**是递增的。
- 括号中的名称与前一条标尺共享刻度，但有自己的印刷数字（例如 `sin2(cos2)`：cos2 是余角 90-theta）。

### 3.5 标尺类型
| 标尺 | 类型 | 用途 |
|---|---|---|
| C / D | 单十进制段对数 | 乘法与除法 |
| A / B | 双十进制段对数 | 平方与平方根 |
| K | 三十进制段对数 | 立方与立方根 |
| CF / DF | 折叠对数（锚定于 sqrt(10)） | 乘法的额外量程 |
| CI / DI / CIF | 倒数（递减） | 除法、倒数 |
| ln1/ln2/ln3 | 对数-对数分段 | 任意次幂与开方 |
| ln1I/ln2I/ln3I | 对数-对数分段的倒数（红色） | - |
| lg | 常用对数线性标尺 | 直接读出 log10 |
| sin2 / cos2 | 三角 | 按角度求正弦 / 余弦 |
| tg2 / tg3 / ctg2 / ctg3 | 三角 | 按角度求正切 / 余切 |
| sh2 / sh3 / th2 | 双曲函数 | sinh / tanh |
| H2 / H3 / H'2 | 双曲函数 | cosh / sech |

## 3.8 标尺约定（已确立）

这些规则由计算尺的使用方式固定下来。它们来自标准文献（见参考资料），并已对照
照片核实。

1. **一切都共享 C/D 基准。** 相对于 C 或 D 读数的标尺，必须以
   `位置与 log10(数值) 成正比` 分度，这样它的刻度才能与 C/D 对齐。这是硬性约束，
   不是风格选择。
2. **右侧注记是读数指令。** `x->y` 告诉你在 C/D 的哪个十进制段读取该标尺的数值：
   - `sin2 .1->1`：正弦值 0.1..1 在 C/D 标尺上读作 1..10（x10）
   - `tg3 1->10`：正切值 1..10 直接在 C/D 上读
   - `sh2 .1->1`、`sh3 1->10`：双曲函数，同理
3. **三角标尺相对于 C/D 读数。**
   - 正弦（`sin2`）：角度约 5.7 到 90 度；`位置 ~ log10(sin)`
   - 余弦（`cos2`，红色）：余角 90 - theta，共享 sin2 的刻度（"达姆施塔特"式
     黑 / 红双标注）。角度数字印在每条刻度略左，红色余角印在其略右，位于同一行
     （`5.5 | 84.5`、`6 | 84`、`45 | 45`），如正面照片所示；`ctg2` / `ctg3` 同理
   - 45 度以下的正切（`tg2`）相对于 C/D 读数；45 度以上（`tg3`）相对于 CI 读数。
     照片显示 `tg3` 终止于 **84.5 度**（tan 10.385，其 ctg3 孪生读数为 5.5），
     刚好越过 C/D = 10
   - `ctg2` / `ctg3` 是余角读数
4. **双曲标尺**（维基百科："Sh ... 用于在 C（或 D）标尺上求双曲正弦"）：
   - `sh2`：双曲正弦，自变量 x = 0.095..0.9（sinh 0.1..1）；注记 `.1->1`，因此
     `sinh(x) = C / 10`；`位置 ~ log10(sinh x)`
   - `sh3`：双曲正弦，自变量 x = 0.85..3（sinh 1..10）；注记 `1->10`，因此
     `sinh(x) = C`；`位置 ~ log10(sinh x)`
   - `th2`：双曲正切，自变量 x = 0.095..∞（tanh 0.1..1）；注记 `.1->1`，因此
     `tanh(x) = C / 10`；`位置 ~ log10(tanh x)`；远端是渐近线 tanh = 1，标记为
     `∞`
   `sh2` / `sh3` / `th2` 的印刷数字是**自变量 x**。它们的位置以 **C/D 十进制
   单位**表示（第 3.8.1 节），*并非*在本段自身跨度上归一化：`sh2` 把 x 放在
   `log10(sinh x) + 1`，`sh3` 放在 `log10(sinh x)`，因此它们的末端伸出 C/D
   两端，并与它们所配合读数的 C/D 刻度对齐。
   - `H2` / `H'2` / `H3`：**双曲标尺**，都按**印刷函数值** `cosh(x)` / `sech(x)`
     的等步长分度（实测，第 3.9 节 —— 子刻度数恰好等于 `(Vb-Va)/step`，而均匀
     自变量步长并不满足这一点）。它们的注记把 x 与相邻的 C 标尺联系起来：
     - `H2` = cosh(x)，`10·sinh(x) = C`；注记 `√1+(.1C)²`；印刷值
       **1.005 .. 1.45**
     - `H'2` = sech(x)，即**反函数**，印刷值 **.995 .. .0**（C/D = 10 处的
       sech 渐近线）；注记 `√1-(.1C)²`
     - `H3` = cosh(x)，`sinh(x) = C`；注记 `√1+C²`（没有括号，因为 C 读数按
       原样使用）；印刷值 **1.4 .. 10.5**
     因此带括号的 `(C)` 始终表示 C 读数需要**先缩放** —— 这里是乘 1/10。
     数值 `sqrt(1+x^2)` 与 `sqrt(1-x^2)` 是毕达哥拉斯关系
     cosh^2 = 1 + sinh^2 与 sech^2 = 1 - tanh^2。
     它们的 C/D 位置遵循与其他行相同的规则（第 3.8.1 节）：`H2` 在
     `log10(sinh x) + 1`，`H'2` 在 `log10(tanh x) + 1`（这就是它**不**随 x
     线性变化的原因，C 发线读取的是关系的 C 值），`H3` 在 `log10(sinh x)`。
5. **折叠标尺**：CF 和 DF 是把 C/D 折叠，使索引落在 sqrt(10)（文献也描述在 pi
   处折叠；本计算尺的照片显示 CF 上是 sqrt(10)，DF 上在折叠跨度的两端都标有
   pi）。第二个十进制段印刷时省略十位（`10` -> `1`、`11` -> `1.1`、`20` -> `2`、
   `30` -> `3`）；DF 的右边缘是 **3.3**（数值 33），而 CIF（CF 的红色倒数）排成
   `3.3 3 2 1.9 ...`。
6. **对数-对数标尺**：`ln1/ln2/ln3` 也以 C/D 十进制单位放置：
   `p = log10(ln x) - log10(from)`，其中 `from` 是注记的下端
   （`1`、`.1`、`.01`）。每对注记就是 `ln(x)` 在该段上的范围，因此 `ln3` 的
   `e` 刻度（ln e = 1）正好落在 D 的左边缘，`ln2` 的落在 C/D 右边缘；`ln1`
   移位两个十进制段，填满同样的宽度。`ln1I/ln2I/ln3I` 是它们的倒数，有各自的
   实测数字。
7. **线性行把数字印在刻度下方。** `lg` 把刻度从其条带的上边缘悬挂，并把
   `0 .1 .2 ... .9 1` 印在刻度**下方**（维护者于 2026-09-17 确认；57 型的 `L`
   行印刷方式相同）。本计算尺其他行尚未检查这一排布，因此它们保持数字在刻度
   上方。
8. **印刷分数省略前导零。** 小于 1 的数值印刷时不写小数点前的零（`0.095` 印为
   `.095`，`0.995` 印为 `.995`，`0.5` 印为 `.5`）；整数则裸印（`0`、`1`）。这
   适用于两个型号的每一行，是共享的标签格式化器
   （`packages/core/src/engine/gradations.ts` 中的 `formatNumber` /
   `trimLeadingZero`）。

### 3.8.1 位置模型：C/D 十进制单位

每条相对于 C/D 读数的标尺都放在 **C/D 十进制单位**中：
`p = 0` 恰好在 `C = 1`，`p = 1` 恰好在 `C = 10`。映射由该标尺的读数关系（其右侧
注记）固定。当印刷自变量 `x` 产生函数值 `f(x)`，且注记对为 `a->b`（`f` 的范围；
注记把读数缩放 `1/a`）时，相邻的 C/D 读数为 `f(x) / a`，因此

```
p = log10(f(x) / a) = log10(f(x)) - log10(a)
```

因此一条标尺可以伸出 C/D 两端。这些刻度仍会绘制 —— C/D 跨度（刻度区自身的
0..1）保持为视觉参考，溢出部分延伸到名称栏或注记面板中；不会做任何钳制或隐藏。

| 标尺 | 注记 | 关系 | 位置 `p` |
|---|---|---|---|
| `C` / `D` | - | 参考十进制段 | `log10(v)` |
| `sh2` | `.1->1` | `10*sinh(x) = C` | `log10(sinh x) + 1` |
| `sh3` | `1->10` | `sinh(x) = C` | `log10(sinh x)` |
| `th2` | `.1->1` | `10*tanh(x) = C` | `log10(tanh x) + 1` |
| `sin2` / `cos2` | `.1->1` | `10*sin(x) = C` | `log10(sin x) + 1` |
| `tg2` / `ctg2` | `.1->1` | `10*tan(x) = C` | `log10(tan x) + 1` |
| `tg3` / `ctg3` | `1->10` | `tan(x) = C` | `log10(tan x)` |
| `H2` | `√1+(.1C)²` | `10*sinh(x) = C` | `log10(sinh x) + 1` |
| `H'2` | `√1-(.1C)²` | `10*tanh(x) = C` | `log10(tanh x) + 1` |
| `H3` | `√1+C²` | `sinh(x) = C` | `log10(sinh x)` |
| `lg` | - | `L = log10(C)` | `L`（线性 0..1） |
| `A` / `B` | - | 两个十进制段 | `log10(v) / 2` |
| `K` | - | 三个十进制段 | `log10(v) / 3` |
| `ln3` | `1->10` | `log10(ln x)` 范围 0.92..9.90 | `log10(ln x)`（e 在 p = 0） |
| `ln2` | `.1->1` | `log10(ln x)` 范围 -0.98..0.03 | `log10(ln x) + 1`（e 在 p = 1） |
| `ln1` | `.01->.1` | `log10(ln x)` 范围 -2.02..-0.98 | `log10(ln x) + 2` |
| `CF` | - | 在 sqrt(10) 处折叠，数值 sqrt(10)..10*sqrt(10) | `log10(v / sqrt(10))` |
| `DF` | - | 在 sqrt(10) 处折叠，数值 3..33（右边缘 3.3） | `log10(v / sqrt(10))`（3 处 p < 0） |
| `CIF` | - | `10 / CF`（数值 `v`） | `log10(sqrt(10) / v)`（3.3 位于 p < 0） |
| `CI` / `DI` | - | C/D 的倒数 | `1 - log10(v)` |

一层范围：`CF` / `DF` 和 `ln*` 行与三角、双曲行一样，相对于 C/D 读数；
`CI` / `DI` / `CIF` 是画在同一框架上的递减倒数。它们每一个都可能溢出 0..1，
且仍被绘制（见上节）。

57 型的 `S`（`log10(sin x) + 1`）、`T`（`log10(tan x) + 1`）和 `ST`
（`log10(sin x) + 2`）遵循同一规则；每条宽一个十进制段，因此落在 0..1 内，不会
溢出。

在代码中，该关系就是标尺的 `calc`（`packages/core/src/types/scale.ts` 中的
`ScaleCalculation`）：它的 `Mapping`（`engine/scaleMapping.ts`）把定义域映射到
位置，游标读取器（`engine/scaleReader.ts`）再映射回来，两者驱动同一个 `calc`，
因此刻度与其读数永远不会不一致。

## 4. 游标

### 4.1 结构
一块透明滑块，沿计算尺全长移动，带有用于对齐标尺和读取的竖直线。

### 4.2 游标线
1. **主线**（中央）：与两个面上的每条标尺对齐。
2. **左侧辅助线**：主线左侧的固定偏移。
3. **右侧 HP 线**：与主线配合用于 kW <-> hp 换算。

### 4.3 游标标尺
游标体上还带有一把自己的对数标尺（C/D 的副本），用于精细估读。

---

## 5. 材料与外观
- **尺体**：塑料（通常为白色）
- **印刷**：黑色与红色
- **标尺名称**：印在每条标尺的开头（左侧）
- **缝**：一条宽间隙，被一条细暗线横穿

---

## 6. 操作
1. **移动动尺**：水平拖动中间带。
2. **移动游标**：沿计算尺拖动透明游标。
3. **翻转计算尺**：显示另一面。
4. **读数**：把游标线与刻度对齐并读出数值。
