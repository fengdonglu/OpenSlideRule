# 模拟器

模拟器是默认视图。它显示计算尺的单个或两个尺面，让你滑动、转动、缩放、放置游标，
并读取每条标尺。

## 选择型号

应用栏左侧的选择器既是页面标题，也是型号选择器：

- **1002 型矢量重对数双面计算尺**——全尺寸双面尺，每面 14 条标尺。
- **五七型便携计算尺**——单面便携尺。
- **已载入规则**——仅在导入规则 JSON 后出现；以文件携带的名称列出。见
  [导入与导出](import-export-cn.md)。

选择器旁的数字是该型号标尺的总数。切换型号会复位动尺、游标和当前显示的尺面。

## 尺面

- **双面**把两个尺面上下叠放，各带一条小标签栏。两面共用一个动尺位置，一条游标线
  贯通两面，因此刻度对齐、读数一致。
- **单面**只显示一个尺面；用**正面** / **背面**选择显示哪一面。

五七型是单面尺，因此**双面**和**背面**对它不可用，提示行会说明该型号没有背面。

## 拖动动尺

中间区域就是动尺。在它任意处按住并向左或向右拖动，光标会变成抓取的手形。动尺向
任一方向最多可移动一整条标尺长度，这使任一索引都能对齐到尺身上的任意值。
**动尺复位**按钮把动尺恢复到对齐位置，动尺已在位时该按钮不可用。

## 缩放

缩放控件位于应用栏中部，范围从 **1X** 到 **6X**：

- **减号**和**加号**每次调整 0.25。
- 数字框可编辑；输入比例并确认。
- 其后的滑块可连续拖动。

在 1X 下计算尺恰好适应视口宽度。高于 1X 时视图可左右滚动，便于查看刻度；缩放会
保持视口中心下方的点不动。

## 游标

游标是贯穿每条标尺的竖线。

- **新增**：点击尺面的空白处。最多允许八个游标；之后的点击会被忽略。
- **移动**：拖动游标手柄或其线条。在已有游标几像素范围内的点击会被视为命中而不
  生效，因此只有拖动才能移动游标。
- **删除**：使用游标读数卡片上的小 **✕**。当指针悬停在该卡片上或它有键盘焦点时
  该按钮出现。删除最后一个游标后，计算尺上不再有游标线；点击尺面即可再次新增。

第一个游标使用主题的游标颜色。之后每新增一个游标，都会从固定调色板中取色，并在
顶部手柄上带有编号，与读数卡片上的编号一致。

## 悬停读数

把指针停在尺面上而不点击。一条虚线参考线跟随指针，可见尺面上的每条标尺都会显示
一个小框，内含标尺名称和参考线下的读数。读数覆盖整个尺面，而不只是 C/D 的 0–1
区间，因此刻度超出 C/D 两端的标尺仍可读取。指针移出尺面即清除读数。

## 读数面板

右侧面板为每个游标保留一张卡片，边框取该游标的颜色。每张卡片按标尺在计算尺上出现
的顺序列出可见尺面上的每条标尺，每行与它所读标尺处于同一高度。双面模式下会出现
**正面**或**背面**标签。

- 读数可编辑。输入数值并按回车（或将焦点移开）；游标会移到读得该值的位置。超出
  范围或在该标尺上无法读取的输入会弹回当前显示值。
- 可移动标尺（动尺，或圆形尺的转盘）的读数旁会**多出一个输入框**（强调色、虚线下
  划线）。在其中输入数值并回车，会移动**动尺**使该标尺在游标处读得该值；游标保持
  不动。这是精确定位动尺的方式：选一条在动尺上的标尺，输入想让它在游标处读到的值，
  动尺即移动到相应位置。行程与拖动一致，上限为一个标尺长度。
- 标尺在游标位置未定义的读数显示为短横线，且不可编辑。
- 可移动标尺会计入当前偏移，因此输入的数值仍能正确落位。
- 面板随游标数量加宽；卡片放不下时可横向滚动。

## 圆形计算尺

圆形计算尺用旋转的转盘取代动尺：

- **转动转盘**：拖动圆盘主体。按下后需移动几像素才算拖动，因此单击不会使圆盘偏移。
- **游标**：点击圆盘即可在该角度新增一条径向游标线，拖动线条或其圆形手柄可移动它。
  颜色、编号和卡片行为与线性视图相同。
- **读数**：面板标题为**读数**，每张卡片列出可见尺面上的标尺。输入数值会把游标转到
  读得该值的角度，并计入转盘偏移。
- **重置转盘**：读数面板中的按钮和应用栏中的复位按钮都会把转盘恢复到印刷对齐位置。

两面都有刻度的圆形计算尺与线性尺一样默认**双面**，两个圆盘纵向叠放；**单面**只显示一个圆盘，并保留**正面** / **背面**切换。

## 主题

**主题**按钮打开一个六宫格，包含：白色塑料、复古竹木、高对比度、金属铝合金、象牙白
和工程蓝图。主题会同时改变计算尺尺面和周围界面的样式，整个页面一起变化。

## 语言

**语言**选择器在简体中文（zh-CN）和 English（en-US）之间切换界面。选择会被记住，
首次访问时应用会跟随浏览器语言，仅对中文区域使用简体中文。

## 键盘微调

方向键可以在不用鼠标的情况下移动计算尺。它**默认开启**；若会与其它快捷键冲突，可用
工具栏中**导入**旁的左右箭头按钮关闭。

- **← / →** 以很小的步长移动动尺。
- **Shift + ← / →** 移动最后一个游标。

开启后，底部提示行会显示该快捷键。焦点在文本或数字输入框时按键会被忽略，因此绝不
会截获正在输入的内容。

## 帮助

**?** 按钮打开型号信息对话框。它列出当前型号的尺面尺寸、行数、标尺总数以及单面或
双面类型，然后按尺面和部位分组列出每条标尺，附简短说明和任何印刷的读法备注。该
对话框还包含**打开快速上手教程**按钮，可重放六步导览。
