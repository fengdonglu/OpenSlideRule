# User Guide

This guide explains how to use the SlideRule 1002 web application: the simulator
of the Chinese 1002 vector log-log double-sided slide rule and the visual rule
designer built into the same page. It is written for readers who want to operate
the instrument on screen or author a rule of their own, not to develop the
software. For the physical instrument and for the code, follow the links at the
end of each page.

The English pages are canonical. A Simplified-Chinese mirror is kept beside each
page as `<name>-cn.md`.
