# 导入与导出

本页介绍如何把规则载入模拟器，以及如何把当前视图导出。设计器有自己的创作稿和定义
导出；这些在[设计器](designer.md)中说明。

## 导入规则

使用以下任一方式：

- 在模拟器工具中点击**导入**按钮，选择一个 `.json` 文件并确认。
- 从文件管理器拖动一个 `.json` 文件，放到模拟器视图上。

文件必须是 `RuleDefinition`——与设计器的**导出计算尺定义**和生成器输出的结构相同。
线性与圆形规则都接受。导入成功后，该规则成为当前型号，以其名称加入型号选择器，并
复位动尺和游标。

导入失败时，当前型号保持不变，并弹出一个标题为**规则载入失败**的对话框：

- **JSON 语法错误**会显示解析器的消息。
- 能解析但未通过校验的规则会显示**校验错误**，逐条列出失败项，格式为
  `path: code: message`。

关闭对话框，然后修正文件或换一个再试。

## 导出

应用栏中的**导出**菜单作用于模拟器，提供四项。

### 导出为 PNG

保存 `sliderule-1002.png`，即当前屏幕上计算尺容器的位图快照，分辨率为屏幕的两倍。
当你想要一张可分享或粘贴到别处的图片时使用它；它精确呈现屏幕内容，包括动尺位置、
游标线和当前主题。

### 导出为 SVG

保存可见尺面的矢量图。线性规则写为 `sliderule-1002.svg`，可见尺面上下叠放、应用
动尺偏移并带白色背景；圆形规则依据渲染器自身的圆盘几何写为
`sliderule-circular.svg`。当你需要可自由缩放的图时使用 SVG，例如编辑，或以任意尺寸
打印而不出现像素化。

### 导出为 Markdown

保存 `sliderule-operations.md`，即在标题和导出时间戳下，以编号列表形式记录的操作
日志。模拟器会在你执行操作时记录——切换型号、切换尺面或单/双面视图、归零动尺或转盘、
新增或删除游标、载入规则、更换主题——因此该文件是本次会话的记录，而不是计算结果。

### 打印 / PDF

打开一个新窗口，其中是当前计算尺的 1:1 图样，然后弹出浏览器的打印对话框。页面按
计算尺自身的毫米尺寸设置，因此打印或选择**另存为 PDF** 都会以真实物理比例输出计算
尺。当你需要物理尺寸的副本而非屏幕图像时，使用此选项。请为应用允许弹出窗口，因为
打印窗口在渲染前就已打开。
