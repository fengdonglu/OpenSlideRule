# 读数原理

计算尺不会替你算出答案；它通过位置来显示数值。模拟器遵循同样的思路：键盘上不解算
任何东西，每个数字都来自标尺停留在游标下的位置。本页解释应用如何产生一次读数。
仪器的理论见[计算尺原理](../domain/slide-rule-101.md)，1002 的标尺见
[1002 型号](../domain/model-1002.md)。

## 标尺与位置

每条印刷带就是一条标尺。标尺有一个从数值到沿尺位置的映射，绘制刻度靠的正是这个
映射。**C**（在动尺上）和 **D**（在尺身上）是参考标尺：大多数其他标尺都相对它们
分度、摆放或读数，因此位置通常用 C/D 十进单位描述，其中 0 对应 C = 1，1 对应
C = 10。相对 C/D 读数的标尺可以超出任一端，而对其实际使用的数值仍然正确；1002
型号记录了这些关系，标尺右侧印刷的 x-to-y 备注会告诉你该在哪一段十进上读数。

红色标尺从右向左递减——例如倒数尺 CI 和 DI。在 1002 上，红色通常表示递减。

## 两种读数方式

应用提供一种临时读数和一种固定读数：

- **悬停读数。** 把指针停在尺面上。一条虚线参考线跟随它，每个标尺行显示一个小框，
  内含标尺名称和该位置的读数。这适合探索：沿着计算尺移动并观察数值。
- **游标读数。** 游标是一条固定线。它在读数面板中的卡片列出该游标处的每条标尺，
  点击或拖动可精确放置它。

两者都由绘制刻度的同一映射产生。因此刻度和它的读数不可能不一致：读取时反转的正是
绘制该刻度所用的映射。在动尺和圆形转盘上，读数会计入当前偏移，因此可移动标尺读的
是它实际占据的位置。

## 为什么读数覆盖整个尺面

读数是在整个尺面上取得，而不只是 C/D 的 0–1 区间。三角、双曲和对数对数等标尺行按
C/D 十进单位分度，可能伸到 C/D 两端之外，进入左栏或右侧备注面板。读取整个尺面能
让这些刻度保持可读，同时每条标尺在自己的定义域之外都不返回值。

## 实际读数

- 对齐动尺，或转动转盘，使你需要的标尺处于你想要的关系；然后在游标处读取一条标尺
  相对另一条标尺的值。
- 用悬停读数找到想要的位置，然后点击放下一个游标，一次读取所有标尺。
- 在游标读数中输入已知值，把游标移到它的位置，这比拖动更便于精确设定。
- 计算尺大约给出三到四位有效数字，且不显示小数点：尺上读作 `2`，但答案是 2、20
  还是 0.2 由你决定。见
  [读数精度](../domain/slide-rule-101.md#4-reading-accuracy)。

关于每个尺面出现哪些标尺及其位置，见[1002 型号](../domain/model-1002.md#3-scales)
中的标尺分布；[术语表](../glossary-cn.md)定义了此处使用的术语。
