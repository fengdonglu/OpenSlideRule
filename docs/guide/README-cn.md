# 用户指南

本指南介绍如何使用 SlideRule 1002 网页应用：它既是 1002 型矢量重对数双面计算尺的
模拟器，也在同一页面内置了可视化计算尺设计器。本书面向希望在屏幕上操作这台仪器、
或自己创作一条计算尺的读者，而非开发软件的人。若想了解实体仪器或代码，请见每页
末尾的链接。

英文页面为准，每页旁边保留一份简体中文镜像，文件名为 `<name>-cn.md`。
